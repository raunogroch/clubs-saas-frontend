1. Lee [guides/QUICK_START.md](./guides/QUICK_START.md) - 10 minutos

## 🎯 Checklists Rápidos

### ✅ Antes de Empezar a Codificar

- [ ] Leí QUICK_START.md
- [ ] Leí guides/README.md (índice de guías)
- [ ] Entendí SOLID_GUIDE.md
- [ ] Revisé un ejemplo en IMPLEMENTATION_GUIDE.md

### ✅ Mientras Codificas

- [ ] Tengo BEST_PRACTICES.md a mano
- [ ] Estoy usando core/hooks (no legacy)
- [ ] Mi código sigue patrones del proyecto
- [ ] Implementé validaciones de errores

### ✅ Antes de Hacer PR

- [ ] Mi código pasa el checklist de BEST_PRACTICES.md
- [ ] Seguí IMPLEMENTATION_GUIDE.md
- [ ] Sin imports deprecated
- [ ] Sin código duplicado
