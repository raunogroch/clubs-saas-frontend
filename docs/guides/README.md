# 📚 Guías Principales

Esta carpeta contiene las **guías principales** para desarrollar en el proyecto. Empieza por aquí.

## 📖 En Orden de Lectura

### 1. 🚀 [QUICK_START.md](./QUICK_START.md) ⏱️ 10 minutos

Introducción rápida al proyecto refactorizado con SOLID.

- Cambios principales
- Ejemplos prácticos
- Checklist semanal

**Perfecto para**: Nuevos desarrolladores y personas curiosas.

---

### 2. 🏗️ [SOLID_GUIDE.md](./SOLID_GUIDE.md) ⏱️ 15 minutos

Explicación de los 5 principios SOLID y cómo se aplican en el proyecto.

- Violaciones encontradas
- Patrones recomendados
- Checklist de implementación

**Perfecto para**: Entender la arquitectura del proyecto.

---

### 3. 💻 [IMPLEMENTATION_GUIDE.md](./IMPLEMENTATION_GUIDE.md) ⏱️ 20 minutos

Cómo usar cada hook, componente y patrón del proyecto.

- Ejemplos de código
- Errores comunes
- Checklist para features nuevas

**Perfecto para**: Escribir código que siga los patrones del proyecto.

---

### 4. ✅ [BEST_PRACTICES.md](./BEST_PRACTICES.md) ⏱️ 15 minutos

Convenciones de código, estructura de carpetas e importes recomendados.

- Patrones a seguir
- Patrones a evitar
- Checklist de code review

**Perfecto para**: Mantener calidad y consistencia del código.

---

## 🎯 Selecciona tu Perfil

**👤 Soy nuevo en el proyecto**

1. Lee QUICK_START.md
2. Lee SOLID_GUIDE.md
3. Prueba los ejemplos en IMPLEMENTATION_GUIDE.md

**🛠️ Voy a escribir código**

1. Lee IMPLEMENTATION_GUIDE.md
2. Consulta BEST_PRACTICES.md mientras codificas
3. Usa el checklist antes de hacer PR

**🏗️ Quiero entender la arquitectura**

1. Lee SOLID_GUIDE.md primero
2. Luego IMPLEMENTATION_GUIDE.md
3. Finalmente BEST_PRACTICES.md para detalles
